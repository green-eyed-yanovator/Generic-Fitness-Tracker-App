This is a little personal hobby project.

I want to create my own fitness tracking app with a special feature:
it can take a video, crop and chop it into pieces and create gifs of 
each fragment. The point is that there are a lot of workouts I see on
Instagram that I want to try but never really get to do because saving 
videos doesn't mean I can actually use it at the gym, because it's 
inconvenient. Cropping them into pieces and turning them into gifs 
that can then be used to create a workout plan inside the app with
timers and each workout having it's own page with the gif, a timer and
notes on what to do.

The rest of the app will be generic useful features.
